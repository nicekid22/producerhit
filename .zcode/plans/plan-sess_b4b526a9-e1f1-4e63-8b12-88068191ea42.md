## Plan d'amélioration du rendu du village vers un style néon cyberpunk AAA

### Problème
Le rendu actuel est un brouillon fonctionnel mais basique (cubes plats, bonhommes bâtons, damier simple). Objectif : village isométrique néon cyberpunk « digne d'un jeu vidéo de bon goût ».

### Direction (confirmée par plan V2)
- Style : néon cyberpunk AAA sombre (Hades/The Ascent)
- Caméra : vue village entier + pan doux au survol
- Ambient : lueurs pulsantes + particules pousières néon + nébulosité
- Zéro asset externe (tout Graphics Pixi procédural)

### Architecture
On garde Stage.tsx manuel (méthode qui marche) mais on décompose en modules :

```
src/engine/
├─ Stage.tsx          Application Pixi + ResizeObserver + camera + boucle principale
├─ iso.ts             palette enrichie + projection + utils
├─ render/
│  ├─ floor.ts        damier hologramme enrichi (emboss + reflections + holo-rings)
│  ├─ buildings.ts    bâtiments détaillés (fenêtres + holo-rings + smokestack)
│  ├─ agents.ts       personnages 2.5D (ombres + outline + accessoires + bulles)
│  ├─ ambient.ts      poussière néon + nébulosité CRT + lunes parallaxe
│  ├─ particles.ts    burst confettis variés + courbes physiques
│  └─ camera.ts       fit + pan doux + clamp + shake on error
├─ World.tsx          (SUPPRIMÉ — dead code)
├─ Buildings.tsx      (SUPPRIMÉ — dead code)
├─ AgentSprite.tsx    (SUPPRIMÉ — dead code)
├─ Floor.tsx          (SUPPRIMÉ — dead code)
├─ Particles.tsx      (SUPPRIMÉ — dead code)
```

### Améliorations par module

**iso.ts** : +palette `floorEdge/floorShadow/ambient/reflection/ORBIT_NEON/LIGHT_POS`, calculs de shading.

**floor.ts** : tuiles embossées (highlight top + shadow bottom), lignes émissives pulsantes, reflets bâtiments au sol, grille hologramme qui scintille, 3 anneaux néon au sol par atelier (pulsent quand actif).

**buildings.ts** : cube iso 3 faces ombrées, fenêtres pixelisées (4x6 grille, certaines allumées aléatoire), panneau hologramme au-dessus (float + glitch), holo-ring au sol qui tourne, antenne + orbe pulsant, smokestack avec fumée montante, dôme holographique semi-transparent, down → gris + halo rouge clignotant, boot → scale-up + flash néon.

**agents.ts** : personnage 2.5D iso (torse arrondi, casque, bras articulés, jambes), ombre portée ellipse graduelle, outline emissive couleur agent, idle variations (rotation lente, blink visière), walk cycle avec micro-bounce + arms swing, accessoires détaillés (clap ciné qui claque pour Studio, micro LED pour Karaoké, casque headphones pour Radio), bulle arrondie border néon style jeu.

**ambient.ts** : 30-50 particules poussière néon qui dérivent en parallaxe, nébulosité CRT grand gradient radial pulsant, scanlines globales, 2-3 lunes/soleils flous en parallaxe derrière bâtiments.

**particles.ts** : confettis formes variées (carré + triangle + étoile), couleurs néon mélangées, courbe physics (gravity + wind rotation + fade-out progressif).
