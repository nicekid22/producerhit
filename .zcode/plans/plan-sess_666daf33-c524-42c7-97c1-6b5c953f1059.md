## Plan : Migration complète Supabase → Firebase

### Problème immédiat : "Job not found"

**Cause racine** : Le `start_job` crée le job dans Firestore pour les users Firebase, mais `poll_job`/`get_job_audio` échouent car `fbGetGenerationJob` ne trouve pas le document. Le problème est probablement que le `firestoreFetch` échoue silencieusement (token, permissions) OU que l'ID du job ne match pas.

**Fix** : Rendre `run_job` purement Firestore (plus de fallback Supabase), et ajouter des logs d'erreur dans `fbGetGenerationJob`.

---

### Phase 1 — Fix immédiat "Job not found" + Firestore-only pour la génération

Fichiers modifiés :
- `supabase/functions/_shared/generateLoopAceMain.ts`
  - `run_job` : Supprimer le fallback Supabase, utiliser uniquement Firestore (`fbGetGenerationJob`)
  - `start_job` : Supprimer le branch Supabase pour Firebase users, toujours utiliser `fbInsertGenerationJob`
  - `poll_job` / `get_job_audio` : Idem, Firestore-only
  - Supprimer le bloc pré-action (lignes 1886-1966) qui essaie les RPCs Supabase pour Firebase users — utiliser `fbCheckUsageIdempotent` directement
  - `bump_usage` : Déjà Firestore-only ✅
  - Auth : Supprimer le fallback Supabase auth, utiliser uniquement Firebase Identity Toolkit

- `supabase/functions/_shared/generationJobUtils.ts`
