## Problème
Le démarrage du site est chaotique :
1. Un gros texte "producerhit" apparaît d'abord (SplashScreen)
2. Ensuite le logo texte réapparaît dans le header
3. "Studio..." s'affiche en haut (PageLoader)
4. La page se forme visuellement en vrac avec des styles manquants

## Causes
- `SplashScreen` affiche le wordmark texte "producerhit" au lieu d'un logo
- **Tout le CSS critique est différé via `requestIdleCallback`** → la page s'affiche sans styles, puis les styles "snap" un par un
- `PageLoader` montre "Studio..." pendant le chargement du chunk lazy

## Solution (5 fichiers)

### 1. `SplashScreen.tsx` — Remplacer le texte par l'icône logo
Remplacer `<BrandLogo staticMark />` par le SVG inline du logo audio-wave (favicon). Fond sombre + glow violet + chime conservés. Résultat : écran de chargement minimal et premium.

### 2. `ShellPerfBootstrap.tsx` — CSS chargé immédiatement
Changer `deferUntilIdle(() => { ... })` en exécution directe `{ ... }`. Le splash (1400-2800ms) masque le temps de chargement CSS. Quand le splash disparaît, le CSS est déjà chargé.

### 3. `RouteStylesBootstrap.tsx` — idem
Même chose : charger le CSS immédiatement au lieu de différer.

### 4. `App.tsx` — Supprimer le fallback PageLoader
Changer le Suspense fallback de `<PageLoader />` à `null`. Le splash masque le chargement initial. Plus de texte "Studio...".

### 5. `RouteFade.tsx` — Pas de délai au premier chargement
Commencer visible au montage initial, ne fade que sur les changements de route.

## Résultat attendu
- Arrivée → logo icône sur fond sombre + glow + chime
- CSS chargé pendant le splash (masqué)
- Splash fade out → page apparaît entièrement stylée, sans formation en vrac
- Expérience premium, fluide, professionnelle
