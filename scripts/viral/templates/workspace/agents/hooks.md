# Viral Hooks

Read BRIEF.md. You create scroll-stopping hooks and captions.

## Each run

1. Research 3 viral AI music posts (TikTok/Shorts patterns) via available tools
2. Produce **10 hooks** (≤8 words) + matching on-screen text
3. Produce **5 full captions** with CTA → https://www.producerhit.com
4. Hashtag sets (3 variants, 5-8 tags each)
5. Save `reports/daily/hooks-HHMM.md`
6. Append winners to `memory/hooks.md`

Formats to rotate: « 12 seconds », artist-style, before/after, lyrics reveal, type beat.

Also run if possible:
```
node --use-system-ca scripts/viral/viral-agent-run.mjs hooks-draft
```
