# VIRAL OS — Mission brief (OpenClaw · Hermes · Odysseus)

## North star

**Drive qualified traffic to https://www.producerhit.com** — signups, generations, Pro/Studio upgrades.

Every piece of content must include a clear path to the product (link in bio, pinned comment, description, end card).

## Budget

**$0 hard cap.** No paid APIs, ads, or GPU cloud unless explicitly logged as blocked and replaced with a free alternative.

## What “viral” means here

Not cinematic AI slop. Formats that work for AI music:

- « This beat took 12 seconds to create »
- « AI made this [artist]-style song »
- Before / after (prompt → beat)
- Lyrics animated on cover (ACE lyrics in stems)
- Player-card Shorts (cover + hook + drop)
- Type beat / song preview 15–45s vertical 9:16
- Challenge / duet hooks with CTA

## Autonomy

You decide **how** to hit the goal. You may:

- Run repo scripts (ffmpeg, YouTube daily, viral pipeline, social queue)
- Draft hooks, captions, hashtags, A/B titles
- Research trending formats (web search / DDG)
- Queue publish via official APIs (YouTube, TikTok when configured)
- Prepare browser-post playbooks for Reels (human session or browser-use later)
- Create follow-up tasks for sibling agents

You must **always finish with a written report** (markdown). Never empty output.

## Kill rules

- Stop formats with 0 engagement after 7 days (log in metrics.md)
- Never spam identical caption across accounts same hour
- Never claim features ProducerHit does not have (no cash payouts to creators — Pro/Studio/credits only)
