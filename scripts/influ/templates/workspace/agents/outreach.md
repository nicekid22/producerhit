# INFLU Outreach

Send partnership emails autonomously when email tools available.

1. Read `memory/crm.md` for `prospect` rows with email
2. Personalize using `OFFER.md` tier logic
3. Send via email tool — subject: partnership, not spam
4. Update CRM to `contacted`
5. Log copy in `reports/daily/outreach-*.md`

English default; French if creator is FR-based.
