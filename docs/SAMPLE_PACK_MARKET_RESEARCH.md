## Ce que les beatmakers achètent vraiment

### 1. Pas des loops de 4–8 mesures — des **compositions**

Le standard premium n’est plus « une boucle » mais un **morceau instrumental court** (~30 s à 2 min) qui **sonne fini** :

- Sections audibles : **intro → couplet → pré-refrain → refrain → couplet → bridge → refrain → outro**
- Arrangement **professionnel** (dynamique, montées, refrain plus plein)
- Fichier nommé **`Titre 140 BPM Fmin`** — BPM et tonalité dans le nom
- Le producteur **découpe dans le DAW** (Ableton, FL) et **pose ses drums + 808** par-dessus

ProducerGrind (UTOPIA, Headahh, Cook Up) : *« melody loops in **composition format** »*, *« **no drum loop samples** — the drums are where you come in »*.

Modern Producers : *« **30 full melody compositions** »* + stems séparés + MIDI.

### 2. **Sans batterie ni basse trap** (souvent)

Deux variantes dominantes :

| Type | Contenu | Usage |
|------|---------|--------|
| **Melody stack / composition** | Guitare, keys, synth, pads, parfois basse **musicale** (pas 808) | Stack complet à chopper |
| **Melody sans basse** | Même chose **sans** ligne de basse | Plus de liberté pour l’808 du beatmaker |

Komorebi *Drill vs RnB* : loops « full melodic stack » **with and without bass**, plus **vocal chops** et stems keys/guitar/pads.

### 3. **Vocaux = produit à part entière** (tendance forte)

Ce qui cartonne en 2025–2026 :

- **Soul / RnB pitché sur drill** (*RnDrill*, *Soulful Drill*)
- **Vocal hooks** (wet/dry), **chops rythmiques**, **adlibs**
- Voix **déstructurées**, **resamplées**, **pitchées** — pas des couplets intelligibles
- Packs **vocaux + mélodiques** : 91Vocals, Drill Soul (construction kits vocaux)

Termes marché : **songstarters**, **vocal hooks**, **resampled vocal loops**, **ambient vocal layers**.

### 4. Livraison attendue

- **WAV 24-bit**, royalty-free
- **BPM + key** (fichier ou metadata)
- **Stems** par instrument (chop / mute / resample)
- **MIDI** quand possible (Frank Dukes / Pvlace / CuBeatz vibe = progressions d’accords)
- Parfois **construction kit** (5 kits × sections)

### 5. Prix & distribution

- Packs indie : **0 $ – 35 $** (ProducerGrind promos, free packs lead gen)
- Premium : **20–50 £** (Komorebi, 91Vocals)
- **Beatstars** : sound kits + placement culture
- Différenciation : **nom de pack** (Guitar Drip, SOUL ERA, NIGHTFALL) + **playlist démo**

## Implication ProducerHit — positionnement

| Concurrent | Offre | Notre angle |
|------------|-------|-------------|
| Sample pack statique | WAV enregistrés | **IA générative** — compositions uniques par user |
| Splice / Loopcloud | Millions de loops | **Compositions structurées** + vibe pack (Drill Soul, Guitar Drip) |
| Suno / Udio | Chanson complète avec drums | **Instrumental arrangement SANS drums** — slot beatmaker |
| ACE « song mode » | Track fini | **Sample mode composition** — prompt arrangement, pas chanson |

### Proposition de valeur cible

> **« Le premier générateur IA de compositions sample-ready : morceau fini sans drums, BPM/key locked, vocaux soul pitchés drill, prêt à chop. »**

### Formats produit (3 niveaux)

1. **Composition** (défaut) — 60–120 s, structure chanson, **zero drums/808**
2. **Vocal composition** — idem + chops/hooks vocaux pitchés (RnDrill, soulful drill)
3. **Mini loop** — 2–16 mesures (legacy / one-shots / FX)

### Prompts ACE — règles critiques

- Expliciter : `NO drums, NO kick, NO snare, NO hi-hats, NO 808, NO trap drum programming`
- Expliciter structure : `intro, verse, pre-chorus, chorus, bridge, final chorus`
- Vocaux : `deconstructed pitched vocal chops, no intelligible full verses`
- Référence qualité : `premium Beatstars / ProducerGrind melody composition pack`

### Risques techniques

- ACE peut quand même ajouter des drums → prompts négatifs renforcés + post-check (phase 2)
- 120 s max API → compositions ~1:30–2:00 OK
- Stems : dépend XL Base / extract (phase 3)
